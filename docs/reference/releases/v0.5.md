# VALANCE v0.5 release notes

## v0.5.0

*Released 2026-10-05 (`v0.5.0`).* A minor release of `@valancex/valance`. It completes the ordinary-website surface: destination links, a derived MESH manifest, a text field that always shows the state's value, a scoped waiting command, a bare-name navigation rule, and a document title that follows the state. It requires **PORT Web 0.3.0**.

### Why a minor

Before 1.0 a minor version is a new range. 0.5.0 adds public API (`Web.link`, `Web.textField`, `Web.controlled`, `Web.event` payload kinds, `command(state).waiting`, `titleOf`, the `@valancex/valance/web/build` manifest, the `Program` and `StateHandle` types) and raises the `@valancex/port-web` peer range from `^0.2.4` to `^0.3.0`.

### What is new

- **Links by destination.** `Web.link` is an `<a href>` primitive. `Web.history({ container })` handles a plain primary same-origin click as navigation; modified clicks, `target`, `download`, foreign origins, `#fragment` links and prevented clicks are left to the browser. A plain click starts the new page at the top; Back and Forward restore the position of the page they return to.
- **A derived manifest.** `manifest` (from `@valancex/valance/web/build`) derives MESH's manifest from the primitives table, the scope schemas and the command table, so it is not written twice.
- **A text field.** `Web.textField` shows exactly the value the application rendered after every presentation (a declined or pre-hydration edit is replaced at the next presentation, the caret is kept while focused). `Web.controlled(name)` is the underlying PORT contract, for a custom input. Needs `@valancex/port-web@^0.3.0`.
- **Waiting commands.** `command(state).waiting(input, { begin?, work, wanted, settle })` is a command whose work is asynchronous: latest wins per command, `wanted` is checked atomically with the commit, a superseded run is not cancelled, and interruption is not failure.
- **Bare navigation.** `Web.history({ navigate: "go" })` (a name without `/`) makes the navigation fact the command's whole input; an exact key behaves as before.
- **Document title.** `history: { titleOf }` sets `document.title` for the first state and every later one.

### Upgrading from 0.4.0

- Install `@valancex/port-web@^0.3.0` if you use `@valancex/valance/web` (the module imports `controlled`, which 0.2.x lacks).
- Nothing else changes for existing applications; an input written with `attribute("value")` and a `Web.event` hook keeps working, and `Web.textField` replaces it.
