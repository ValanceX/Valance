# Install

One command installs everything.

```bash tab="npm" group="pkg"
npm install handbook
```

```bash tab="pnpm" group="pkg"
pnpm add handbook
```

> [!NOTE]
> Version 1 needed three commands. See [upgrading](/docs/upgrading) if you are coming from it.
