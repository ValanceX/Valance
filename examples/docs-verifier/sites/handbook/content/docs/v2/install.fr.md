# Installation

Une seule commande installe tout.

```bash tab="npm" group="pkg"
npm install handbook
```

```bash tab="pnpm" group="pkg"
pnpm add handbook
```

> [!NOTE]
> La version 1 demandait trois commandes. Voyez la [mise à niveau](/docs/upgrading) si vous venez de celle-ci.
