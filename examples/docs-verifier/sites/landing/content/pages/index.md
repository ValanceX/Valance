# Weave small programs into one you can read

Loom keeps every piece of an application in plain sight: what it knows, what it does, and what it shows.

- [Get started](#features)
- [Read the source](https://example.com/loom)
:::

## Features

::: cards
- [One value](#features) The whole state in a single place, validated where it enters.
- [Commands](#features) The only way to change it, with loading and failure as ordinary values.
- [Views](#features) Written once, drawn on a server and in a browser.
- [Plugins](#features) A head, a router and a set of tags are passed in, not wired.
:::
