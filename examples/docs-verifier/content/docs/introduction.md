# Introduction

Valance keeps an application's state in one place. The screen is a function of that state, and a command is the only way to change it.

> [!NOTE]
> This site is the features verifier: it is built on the development branches of MESH and PORT to find where composing an application is still a chore.

## What you get

- State in one value, validated where it enters.
- Views written once, in MPRX, and drawn on the server and in the browser.
- Commands that can wait, with loading and failure as ordinary state.
