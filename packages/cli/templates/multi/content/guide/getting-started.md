# Getting started

Edit `content/index.md` and save: the window shows it.

> A link is an address. In a window, following one is the application's own navigation, the same command the web uses.

1. Add a page: a Markdown file under `content/`.
2. Change the window: `src/layout.mprx`, with the components `column`, `row`, `heading`, `text`, `button`, `checkbox` and `textfield`.
3. Add state or a command: `src/main.ts`.
